# 📸 Ubuntu Captions

Welcome to **Ubuntu Captions** — an African-inspired photography website designed to capture culture, emotions, beauty, and unforgettable moments through powerful visual storytelling.

Inspired by the philosophy of **Ubuntu** — *“I am because we are”* — this website celebrates creativity, connection, and humanity through photography.

---

## Features

* Modern African-inspired design
* Responsive image gallery
* Cinematic hero section
* Smooth hover animations
* Mobile-friendly layout
* Contact section
* Portfolio showcase

---

##  Getting Started

### Clone the repository

``` 
git clone https://github.com/cymi-eng/ubuntu-captions.git
```

### Open the folder

```
cd ubuntu-captions
```

### Run the website

Open `index.html` in your browser
